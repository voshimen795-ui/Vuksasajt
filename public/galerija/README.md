# Fotografije sa terena

Ovde idu stvarne fotografije izvedenih radova. Postupak:

1. Ubacite fotografiju u ovaj folder, npr. `hladnjaca-ats.jpg`.
2. U `src/data/projects.ts` dodajte stavci polje:
   `image: "/galerija/hladnjaca-ats.jpg"`.

Bez tog polja kartica prikazuje crtež agregata kao rezervu.

Preporuka: vodoravna fotografija, najmanje 1200 × 800 px, do ~500 KB
(JPG, kvalitet 80). Bez logotipa naručioca i bez prepoznatljivih podataka
o klijentu.
